# Security Policy

## Supported versions

Security updates are provided for the latest released version of this package.

## Reporting a vulnerability

Please report security issues privately. Do not open a public GitHub issue for a vulnerability.

Email **hello@blendbyte.com** with:

- A description of the issue
- Steps to reproduce, or a proof of concept
- The package version and PHP/Laravel versions involved
- Any known impact or exploitability notes

You can also use [GitHub private vulnerability reporting](https://github.com/blendbyte/coyotecert-laravel/security/advisories/new) on this repository.

We will acknowledge receipt within a few business days and keep you informed while we investigate and ship a fix. Please give us a reasonable window to release a patch before any public disclosure.
